# Локальные HTTPS-сертификаты (только для разработки)

Эта папка нужна, чтобы тестировать PWA, push и офлайн-режим с телефона по `https://192.168.x.x:5173`.

## Сгенерировать сертификаты

Из корня проекта:

```powershell
npm run certs:generate
```

Скрипт создаст `certs/key.pem` и `certs/cert.pem` и покажет IP для телефона.
Если сертификатов нет, `npm run dev:https` всё равно поднимет HTTPS через fallback-плагин Vite.

## Запуск с HTTPS

```powershell
npm run dev:api
npm run dev:https
```

На телефоне откройте адрес, который покажет скрипт (например `https://192.168.1.100:5173`).

Браузер предупредит о самоподписанном сертификате — это нормально для локального теста.

## Что удалить перед продакшеном

| Что | Зачем удалять |
|-----|----------------|
| `certs/` (вся папка) | Сертификаты только для локального теста |
| `frontend/.env.https` | Включает dev-режим HTTPS и service worker |
| Блоки `DEV-HTTPS` в `frontend/vite.config.ts` | HTTPS в Vite нужен только локально |
| Блок `DEV-HTTPS` в `frontend/src/main.ts` | Включение SW в dev-режиме |
| Скрипты `certs:generate`, `dev:https` в `package.json` | Только для локальной разработки |

На продакшене используйте нормальный домен и сертификат (Let's Encrypt / nginx), а не эти файлы.
